09 // ARCHITECTURAL DECISIONS

Key Technical Trade-offs & Engineering Justifications

Defending core engineering choices against common design alternatives.

1. Resolution Scaling: 128px vs 224pxINPUT SPEC
Choice: 224×224 input resolution.
Rationale: At 128×128, subtle nose bridge gaps in incorrect mask wearing were compressed into indistinguishable blur. 224px captured fine strap lines while maintaining 60+ FPS edge throughput.
2. Class Weighting vs Naive OversamplingLOSS DYNAMICS
Choice: Inverse frequency class weighting in cross-entropy loss.
Rationale: Naive oversampling caused feature overfitting on minority classes. Loss weighting penalized errors on rare classes without duplicate sample memorization.
3. MobileNetV2 vs Vision Transformers (ViT)LATENCY / BUDGET
Choice: MobileNetV2 depthwise separable CNN.
Rationale: ViT architectures require 80M+ parameters and 120ms latency per frame. MobileNetV2 achieved 99.55% accuracy at 3.5M parameters and 14ms latency, enabling smart camera deployment.
4. Cryptographic Test IsolationDATA HYGIENE
Choice: Full MD5 verification on raw payloads prior to partition.
Rationale: Public datasets contain identical images across different source folders. Hashing eliminated 2,688 duplicate leaks, ensuring genuine zero-snooping test validation.
